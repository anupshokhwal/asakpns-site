# asakpns-site

Company website for ASAKPNS, live at https://asakpns.com.

Plain HTML and CSS, no build step. Hosted on Cloudflare (Workers static assets).

- `index.html`: home page
- `privacy.html`: privacy policy (website and apps)
- `styles.css`: brand colors and layout
- `favicon.svg`: browser-tab icon
- `sitemap.xml`, `robots.txt`: for search engines
